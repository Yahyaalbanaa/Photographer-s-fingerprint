# فوتوهب - منصة ربط المصورين بالعملاء

## 📸 نظرة عامة

**فوتوهب** هي منصة إلكترونية متكاملة تهدف إلى ربط المصورين المحترفين مع العملاء الذين يبحثون عن خدمات تصوير احترافية. المنصة توفر واجهة مستخدم عصرية وسهلة الاستخدام بتصميم عربي أصيل.

## ✨ المميزات الحالية المنفذة

### 1. الصفحة الرئيسية (index.html)
- واجهة مستخدم جذابة مع قسم Hero
- عرض رسالة ورؤية وقيمنا المنصة
- قسم الفريق مع صور الأعضاء
- قائمة تنقل احترافية
- تصميم متجاوب لجميع الأجهزة

### 2. نظام المصادقة والحسابات
- **صفحة تسجيل الدخول** (login.html) - للمستخدمين المسجلين
- **صفحة اختيار نوع الحساب** (account-type.html) - اختيار بين مصور أو عميل
- **صفحة إنشاء حساب عميل** (register-client.html) - تسجيل للعملاء
- **صفحة إنشاء حساب مصور** (register-photographer.html) - تسجيل للمصورين مع رفع أعمال
- **صفحة استعادة كلمة المرور** (forgot-password.html) - لاستعادة الحساب
- **صفحة إدخال رمز التحقق** (verify-code.html) - للتحقق من الهاتف

### 3. الصفحات القانونية والمساعدة
- **صفحة الشروط والأحكام** (terms.html) - شروط استخدام المنصة
- **صفحة 404** (404.html) - صفحة الخطأ المخصصة

### 4. التصميم الموحد
- نظام ألوان متسق (أحمر داكن #dc2626 على خلفية بنية داكنة)
- خط Cairo العربي الاحترافي
- تأثيرات حركية وانتقالات سلسة
- تصميم متجاوب بالكامل (Mobile-First)
- أيقونات ورموز تعبيرية موحدة

### 5. التفاعلية (JavaScript)
- تنقل تلقائي بين حقول رمز التحقق
- رفع الملفات بالسحب والإفلات
- التحقق من صحة النماذج
- رسائل تأكيد للعمليات
- تمرير سلس للروابط الداخلية

## 🔗 روابط الصفحات الوظيفية

### للمستخدمين الجدد:
1. **البداية**: `index.html` → الصفحة الرئيسية
2. **التسجيل**: `account-type.html` → اختيار نوع الحساب
   - **للعملاء**: `register-client.html`
   - **للمصورين**: `register-photographer.html`
3. **التحقق**: `verify-code.html` → إدخال رمز التحقق
4. **اكتمال التسجيل**: العودة إلى الصفحة الرئيسية

### للمستخدمين المسجلين:
1. **الدخول**: `login.html` → تسجيل الدخول
2. **نسيان كلمة المرور**: `forgot-password.html` → استعادة الحساب

### صفحات إضافية:
- **الشروط والأحكام**: `terms.html`
- **صفحة الخطأ**: `404.html`
